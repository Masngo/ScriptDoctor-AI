## 🚀 Overview

**ScriptDoctor AI** is an advanced multi-agent assistant designed for screenwriters, script coverage analysts, and production studios. It automatically scans screenplays in real time to identify historical anachronisms, factual inconsistencies, and temporal errors—then instantly provides period-accurate remediation scripts and AI pre-visualization video previews.

---

## ✨ Key Features

* **🤖 Multi-Agent Auditor Fleet**: Employs a collaborative agent pipeline—parsing temporal markers via Agent 1, querying historical databases via Parallel MCP (Agent 2), and synthesizing narrative fixes via Gemini 3.5 Flash (Agent 3).
* **⚡ Parallel MCP Grounding**: Utilizes real-time search context to verify tech introductions, vehicle timelines, and historical accuracy against authoritative indexes.
* **📊 Agent Audit Telemetry Dashboard**: Features an intuitive hacker/cyberpunk-themed Streamlit interface complete with **Agent Fleet Standby** states, risk metrics, and reasoning trace logs.
* **✏️ One-Click Auto-Remediation**: Instantly swaps out script violations (e.g., an iPhone 15 in a 1998 police precinct) for period-accurate alternatives.
* **📹 Pre-Vis Scene Video Embeds**: Dynamically generates and renders scenario video previews directly inside the dashboard.

---

## 🛠️ Tech Stack

* **Core Intelligence**: Gemini 3.5 Flash, Google Cloud Agent Builder
* **Context & Tooling**: Parallel Search Model Context Protocol (MCP) Server
* **Frontend & UI**: Streamlit (Python)
* **Script Formatting**: Fountain standard markup support
